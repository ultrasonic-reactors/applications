# Ultrasonic Reactors — website

Website for the **Ultrasonic Reactors** technology of the University of Alicante
(Research Results Transfer Office — OTRI).

Live at [ultrasonicreactors.com](https://ultrasonicreactors.com).

## Development

Plain HTML, CSS and a little vanilla JavaScript — no build step, no framework.
Push to `main` and GitHub Pages deploys automatically.

```
index.html                  Home ("Flow Chemistry")
our-experience/index.html   Our Experience
news/index.html             News
contact/index.html          Contact
404.html                    Not-found page
assets/css/style.css        Single stylesheet
assets/js/waves.js          Hero background animation
assets/img/                 Images and animations
```

Local preview:

```bash
python3 -m http.server 8000
```
